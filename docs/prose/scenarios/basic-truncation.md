Often times, elections using a form of RCV limit the number of candidates that voters can rank on their ballots - even for elections with large candidate pools. In this scenario, we ask how the electoral system modeled in the Basic scenario would be impacted if we set a minimum and maximum ballot length in each of the 3 X 3 STV district contests. We run two different simulations; one of them sets the maximum ballot length to six, and the other pins it to 10 ranked candidates. In each simulation, we enforce a minimum ballot length of three since each district has three seats available.
