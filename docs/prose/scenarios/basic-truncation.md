Often times, elections using a form of RCV limit the number of candidates that voters can rank on their ballots - even for elections with large candidate pools. In this scenario, we ask how the electoral system modeled in the Basic scenario would be impacted if we set a minimum and maximum ballot length - specifically in the 3 X 3 STV district contests. We set the maximum ballot length to six ranked candidates, and enforce a minimum ballot length of three since each district has three seats available.
